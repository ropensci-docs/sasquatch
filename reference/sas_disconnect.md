# Disconnect SAS session

Disconnects from the current SAS session.

## Usage

``` r
sas_disconnect()
```

## Value

No return value.

## See also

Other session management functions:
[`sas_connect()`](https://docs.ropensci.org/sasquatch/reference/sas_connect.md),
[`sas_get_session()`](https://docs.ropensci.org/sasquatch/reference/sas_get_session.md)

## Examples

``` r
if (FALSE) { # interactive()
sas_connect()

sas_disconnect()
}
```
